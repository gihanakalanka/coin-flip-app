# Coin Flip 🪙

A luxury 3D coin flip mobile app featuring physics-based animations, consecutive streak tracking, and satisfying audio feedback. Built entirely from prompt to production using **Google AI Studio**.

📺 **[Watch the full build tutorial on UX Alchemy](https://youtu.be/O1GjNf-RcyQ)**

## ✨ Features
* **3D Animated Physics:** Smooth, realistic coin flipping mechanics built with React Native's Animated API.
* **Streak Tracking:** Dynamic consecutive flip counters with visual flash milestones and winning celebrations.
* **Audio & Haptics:** Premium sound effects integrated for every flip.
* **Zero Code Generation:** Generated as a ready-to-run single file via Google AI Studio using voice dictation.

## 🛠️ Tech Stack
* React Native
* Expo
* Tailwind CSS
